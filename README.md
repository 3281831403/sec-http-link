sec-http-link
=============

预加载策略上线后，安全团队发现同一段 Link 头在网关与浏览器侧被解析成不同的链接集合：目标地址里的逗号把一条链接拆成两条，带分号的标题被截断，一个响应里多个匹配的链接只生效第一个，重复目标合并后反而出现两条，声明 preload 却没有 as 的项也被下发给客户端。契约要求：字段值按逗号切分链接，但尖括号内的目标地址与引号内的参数值都不参与切分；每条链接以尖括号目标开始，其后的参数按分号切分，同样跳过引号内内容；参数名大小写不敏感并统一为小写，同名参数按出现顺序合并而不是后者覆盖，关系类型在引号内再按空白拆成多个令牌；解析结果中每个链接由目标与参数映射组成，参数映射的值为字符串列表；序列化时关系类型始终加引号，其余参数只在值不是合法令牌时才加引号，并转义反斜杠与双引号；按关系查找必须返回全部匹配项且关系名大小写不敏感；合并两条链接列表时以目标地址为准去重，关系类型取并集并保持先出现顺序，其他参数冲突时保留先出现的值；预加载输出只保留同时声明 preload 与 as 的项，目标地址无论相对还是绝对都原样保留。不变量：解析与序列化往返后参数结构不变；合并满足幂等，重复合并不改变结果；查询结果顺序与输入一致；同一输入重复处理结果相同。
